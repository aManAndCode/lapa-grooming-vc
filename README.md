# 🐾 Лапа — салон стрижки собак

Лендинг с живым калькулятором услуг и формой записи. Первый тестовый проект в формате «вайб-кодинга».

## Что внутри

- **Услуги**: стрижка, купание, когти — можно выбрать любую комбинацию.
- **Калькулятор по размеру собаки** — маленькая (×1), средняя (×1,3), большая (×1,5), с счётчиком количества по каждому размеру.
- **Форма записи**: имя хозяина, телефон, кличка, дата.
- После отправки — экран «Заявка принята» с чеком и итоговой суммой.
- Статья про уход за шерстью и промо-баннер.

## Как запустить

Это одностраничный сайт на чистом HTML/CSS/JS — файл `index.html` открывается в любом браузере без сборки и сервера.

### Вариант 1 — открыть локально
Скачайте `index.html` и откройте его двойным кликом (или через браузер: «Открыть файл»).

### Вариант 2 — через GitHub Pages
Если включить Pages для этого репозитория (Settings → Pages → Branch: `main` → Save), сайт будет доступен по ссылке:

```
https://amanandcode.github.io/lapa-grooming-vc/
```
